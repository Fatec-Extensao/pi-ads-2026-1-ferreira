# Modelagem UML

Esta pasta reúne os artefatos de modelagem UML do sistema **Web para Gestão de Pesquisas por Questionários**, produzidos na disciplina de Engenharia de Software.

## 📄 Conteúdo

- [**casos-de-uso.md**](casos-de-uso.md) — Diagramas de casos de uso do sistema, organizados por módulo funcional, com as imagens `caso-de-uso-01.png` a `caso-de-uso-06.png`.
- [**especificacao.md**](especificacao.md) — Especificação dos fluxos principais e alternativos de cada caso de uso, representados pelos diagramas de atividade.

Os arquivos `.png` presentes nesta pasta correspondem aos diagramas referenciados nos arquivos acima (casos de uso e diagramas de atividade). Eles são exibidos automaticamente ao abrir os respectivos `.md`, não sendo necessário acessá-los individualmente.
